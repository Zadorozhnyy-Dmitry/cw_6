## Курсовая 6. Основы веб-разработки на Django. Разработка сервиса рассылок


#### Для запуска проекта создайте в корне проекта файл .env следующего вида:
```commandline
# настройки Джанго
SECRET_KEY=***
DEBUG=True
# настройки БД
NAME=***
USER_DB=postgres
PASSWORD=***
HOST=127.0.0.1
PORT=5432
# настройки почтового сервера
EMAIL_HOST=smtp.****
EMAIL_PORT=465
EMAIL_HOST_USER=***
EMAIL_HOST_PASSWORD=****
EMAIL_USE_TLS=False
EMAIL_USE_SSL=True
# настройки редис
LOCATION=redis://127.0.0.1:6379
```


### Выполняются требования:

+ Интерфейс системы содержит следующие экраны: 
  - список рассылок,
  - отчет проведенных рассылок отдельно,
  - создание рассылки,
  - удаление рассылки,
  - создание пользователя,
  - удаление пользователя,
  - редактирование пользователя.
  

+ Приложены фикстуры для заполнения базы данных

+ Реализован интерфейс заполнения рассылок
+ Реализован скрипт рассылки, который работает как из командной строки, так и по расписанию
+ Добавлены настройки конфигурации для периодического запуска задачи при необходимости
+ Пользователь регистрируется и верифицируется по почте
+ Доступа к рассылкам для разных пользователей ограничен
+ Реализован интерфейс менеджера
+ Создан блог
+ На главной странице указана следующая информация:
  - количество рассылок всего
  - количество активных рассылок
  - количество уникальных клиентов для рассылок
  - три случайные статьи из блога
+ Для блога и главной страницы настроено кеширование
